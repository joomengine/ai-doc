# Field Type fixture operating rules

This is a documentation fixture, not a production Field Type source. Its GUID is permanently reserved for the example. Follow the [Field Types module](https://github.com/joomengine/skills/tree/main/field-types) and the enclosing documentation branch's instructions when reviewing a proposed update.

Preserve the imported `item.json` structure and matching `index.json`. Target evidence is Joomla 6.2.0 and the recorded JCB 6.x snapshot. The Text catalogue profile reuses the core runtime class. Same-item production improvements or overrides must retain the official Text GUID; a genuinely new Field Type requires a cryptographic UUIDv4 checked against the current official `joomengine/joomla-fieldtypes` index, additional configured catalogues and local additions.

Report static validation separately from JCB import, compilation and runtime checks. Do not publish or reuse this fixture identity.
