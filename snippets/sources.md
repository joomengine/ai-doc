## Observed differences and known gaps

- Core contains 353 snippets and 40 types. All current snippet records use string-valued ordinary fields plus a dependency array. This observation does not make null handling or historical data identical across every JCB version.
- The core references Bootstrap v4 (`6f6650a5-ebff-4783-8508-f0285c0e98a6`, 327 snippets) and UIkit v2 (`5eeee148-cebd-4a92-bc0e-56efea3cffdc`, 26 snippets). These library records are external to the snippet repository; current seed data identifies them, but browser availability/assets remain a consumer check.
- Current `SnippetsField::getOptions()` emits GUID option values, while its older inline edit helper still tests a numeric value and builds an `id=` URL. A missing edit button is not evidence that repository GUIDs should become numeric IDs.
- Initial options/details accept `published >= 1`; selected-library filtering uses `published = 1`. An archived local record may therefore behave differently across paths. Publication state is local, not an invented repository field.
- The preview JavaScript concatenates returned metadata/source into HTML. It is not a sandboxed source viewer. Review trusted catalog changes before rendering; static JSON validation is not sanitization.
- The modern importer/exporter differs from the legacy flat sharing path. No automated legacy migration or universal cross-version import compatibility is claimed.
- Real JCB import/reset/export, compiled extension execution and browser accessibility remain unexecuted unless separately recorded in verification. The module provides a precise procedure for those checks.

## Refresh procedure

Before relying on a changed target, record current core and JCB branch commits. Diff the source-map paths above, the field/type schemas and the consumer paths; re-survey catalog shapes and dependencies. Update only claims supported by the new source. Run the shipped validators and repeat affected integration checks. Keep the official core in the discovery registry, retain intentional override order, and do not treat a new inspection date by itself as evidence of compatibility.
