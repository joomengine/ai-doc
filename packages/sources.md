## P01

**Inventory, fields and relations.** [Componentbuilder/Table.php](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Table.php) defines mapped fields, storage, DB metadata and nested links. [Componentbuilder/Power/Table.php](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Power/Table.php) implements `parents`, `children`, `search`, `isValidParent` and recursive subform handling. Generic outgoing links require type `1`, complete link metadata and key `guid`; type `2` is not a generic entity link.

[Componentbuilder/Factory.php](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Factory.php) maps canonical entity names to area/factory; [Package/Factory.php](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Package/Factory.php) registers available handlers. The 42 [Package remote configuration classes](https://github.com/vdm-io/Joomla-Component-Builder/tree/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Package) cover 40 database entities plus separate File/Folder handlers for `file_system`. Table existence and compiler consumption alone do not create a Package configuration.

Use [model-contracts.json](model-contracts.json) and the [field reference](reference/README.md) to locate each configuration and [admin/forms](https://github.com/vdm-io/Joomla-Component-Builder/tree/408703a857ad937479b1e28de7f693af178dcc83/admin/forms) definition. Table DB defaults, UI defaults/options and repository values answer different questions. Conditional UI rules and compiler consumers may further restrict a syntactically valid value.

## P02

[Abstraction/Remote/Base.php](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Abstraction/Remote/Base.php#L354) supplies `mapItem`, `getIndexItem` and the `index_map_*` functions. Per-type README suppression is intentional configuration.

## P04

**Storage encoding and skipped nulls.** [Service/Data.php](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Service/Data.php) wires model-backed loading/insertion/update. [Model/Load.php](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Model/Load.php) decodes Base64 and JSON; [Model/Upsert.php](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Model/Upsert.php) encodes those modes, with `JSON_FORCE_OBJECT` for JSON. Other named store modes are not handled by additional cases in these generic methods.

[Abstraction/Model.php, `item()`/`row()`](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Abstraction/Model.php#L185) iterates known fields with `isset`, excludes unknown/null members and requires more than one modeled field; `allowEmpty` defaults true. [Data/Item.php, `set()`](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Data/Item.php#L207) chooses insert/update by the configured key. These explain why double-encoded structured values are wrong and null is not a reliable clear instruction. They do not say every JSON-stored value must be an object: inspect the specific field, including scalar Field XML.

## P05

**Repository order, branches and caching.** [Package/Config.php](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Package/Config.php) builds the legacy core-org `packages:master` fallback and prepends configured target-4 sources. [Utilities/RepoHelper.php](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Utilities/RepoHelper.php#L39) queries published records in descending order and normalizes host/token details. Prepending reverses distinct entries into ascending numeric order; duplicate owner/repository keys can collapse before search.

[Abstraction/Grep.php](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Abstraction/Grep.php) implements `validRepo`, `getBranchName`, `searchSingleRepo`, `existsRemotely` and `indexRemote`. Empty/`default` read branch resolves through the host default; first index match wins; cached indexes and explicit reload are separate from local database refresh. [Package/Grep.php](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Package/Grep.php) selects the `package` network target and dependency trait. [Repository form](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/admin/forms/repository.xml) defines separate provider/target/read/write fields.

## P06

**Descriptor extraction and supported discovery.** [Package/Dependency/Resolver.php](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Package/Dependency/Resolver.php#L228) provides:

- `extractParents` / `extractChildren`: Table links and existing allowed children.
- `extractDynamicContent`, `getCustomCode`, `getTemplates`, `getLayouts`, `getPlaceholders`: the literal supported text forms and local alias/placeholder lookup requirements.
- `extractSubformFields` / `extractValidationRule`: specific Field Type GUID and double-quoted XML scans.
- `record` / `validValue`: typed descriptors, in/out direction, deduplication and minimum non-GUID string checks.
- `recordFile` / `recordFolder`: destination descriptors and local-only absolute paths in export queues.
- `setAliasMap` / `setGuid`: alias variants and possible assignment of missing local Template/Layout GUIDs.

There is no generic Super/Joomla Power token extraction method here. [Remote/SetDependenciesTrait.php](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Remote/SetDependenciesTrait.php) accepts nonempty descriptor key/value/entity, separates filesystem requests and guards already-attempted keys. It is not a complete validator of table/key consistency. [Package/Dependency/Tracker.php](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Package/Dependency/Tracker.php) supplies request-scoped tracking.

## P07

**Initialization, Pull, Reset and dispatch.** [Abstraction/Remote/Get.php](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Abstraction/Remote/Get.php#L115) implements local-first `init`, read branch selection, early attempt guards and the unchecked setter result before adding an `added` category. Its `item` path checks the setter result.

[Package/Builder/Get.php](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Package/Builder/Get.php#L124) passes the same explicit repository/force flag to recursive initialization; `get` uses global lookup. `reset` drains the entity queue and only recurses through `getDirectChildrenGuids` (`direction == in`), then resets assets. It does **not** initialize the filtered outgoing dependencies. Missing registered services are skipped. `mergeResults` combines value-keyed buckets, not a full typed provenance graph.

[Joomla_componentsController.php](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/admin/src/Controller/Joomla_componentsController.php#L148) exemplifies permissions/token handling, Component selection-screen routes and selected-local-key Reset/Push. [AjaxModel.php selection methods](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/admin/src/Model/AjaxModel.php#L6770) distinguish Init from forced Pull. [Package service providers](https://github.com/vdm-io/Joomla-Component-Builder/tree/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Package/Service) establish which handlers are available; the independent Field Type remote service is not registered merely by its descriptor appearing in a Package graph.

## P08

**Push destination scope, comparisons and partial writes.** [Package/Builder/Set.php](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Package/Builder/Set.php#L88) dispatches selected roots, drains discovered entities and transports assets. [Abstraction/Remote/Set.php](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Abstraction/Remote/Set.php#L514) maps records, extracts dependencies and loops all eligible repositories. `targetRepo()` returns true in this generic path; `canWrite`/`save` reject missing/empty/literal-default write branches. This is different from per-Power approval metadata.

`save` queues index metadata on creation, not ordinary update. `saveRepoMainSettings` and `mergeIndexSettings` reload/merge existing indexes, preserving unrelated entries. [Componentbuilder/Remote/Set.php](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Remote/Set.php) serializes mapped objects, conditionally writes READMEs and compares dependencies. `dependenciesEqual` is order-insensitive but count/multiplicity-sensitive despite its set-oriented docblock. Missing source SHA and equal data both use the no-change warning route. There is no transaction across writes or destinations and no automatic deletion sync.

## P09

**Assets, deterministic keys and restoration limits.** [File config](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Package/File/Remote/Config.php) and [Folder config](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Package/Folder/Remote/Config.php) share `file_system`, `index/file_folder.json`, `src/file_folder`, `key`, empty settings filename and a name/path/guid index. [Package/GrepContent.php](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Package/GrepContent.php) fetches index.path directly and adds content to the index object. [Remote/GetContent.php](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Package/Remote/GetContent.php) uses the descriptor's destination for Init/Pull but key-only retrieval for Reset. Its `item` requires fetched `value`/`target`, absent from stock index entries; this is the documented Reset source limitation, not a claimed live reproduction.

[GetFile.php](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Package/Remote/GetFile.php) and [GetFolder.php](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Package/Remote/GetFolder.php) remove existing targets before writing/restoring and catch/report failures. [SetContent.php](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Package/Remote/SetContent.php), [SetFile.php](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Package/Remote/SetFile.php) and [SetFolder.php](https://github.com/vdm-io/Joomla-Component-Builder/blob/408703a857ad937479b1e28de7f693af178dcc83/libraries/vendor_jcb/VDM.Joomla/src/Componentbuilder/Package/Remote/SetFolder.php) write raw file/ZIP content and compare Git blob hashes. PHP `empty` rejects empty content (including string `"0"`) in the inspected transfer paths.

## Refresh and completion requirements

1. Record the intended JCB revision and actual installed Joomla/JCB/PHP target. Refresh catalogue revisions without silently changing the user's working tree.
2. Compare every remote config, specialized writer, table/form projection and service registration; regenerate inventory/reference data together. Do not count configurations as entities without accounting for File/Folder's shared transport.
3. Recheck identities, ignored fields, source-specific selectors, encoding and null/update behavior. Trace new relationships through both discovery and dispatch; a declared edge alone does not guarantee an available handler.
4. Recheck order, read/default/write branch handling, selected-repository recursion, Reset direction filtering, asset destination reconstruction, output index refresh and partial-write behavior.
5. Validate the representative complete graphs and meaningful negative cases; follow the [Package integration procedure](workflows/validate-and-integrate.md) on the intended branch. Preserve new-import and existing-item-refresh evidence separately.
6. Record performed, failed, blocked and not-run checks. Distinguish source-observed limitations from live reproductions and use the [human-led issue procedure](../testing/reporting-issues.md) when reporting a reproduced JCB defect. Never turn a static pass or an unrelated prior Playground import into Package runtime acceptance.
