# Fixture operating boundary

This directory is a maintained original package fixture, not a production starter with reusable new identities. Read `README.md` and the package module at `https://github.com/joomengine/ai-doc/tree/main/packages` before changing it. Apply that module's identity, dependency, serialization, asset, validation and Playground acceptance rules.

Keep the fixture UUIDs/natural keys stable when maintaining this same example. A distinct application needs fresh checked identities and coherent graph/path/reference changes. Preserve the external core Text Field Type identity. JSON payloads and raw assets are authoritative; indexes must agree. Do not claim import, compilation or runtime checks that were not executed.
